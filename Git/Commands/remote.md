# `git remote`

**Concept:** Git
**Action:** Manage
**Object:** `git remote`
**Classification:** Command
**Environment:** Git
**Path Type:** N/A
**Tags:** command

---

### What It Is

A Git command that manages the set of tracked remote repository references.

### What It Does

Lists, adds, removes, or renames the remotes a local repository knows about.

### How to Use

Run `git remote` with a subcommand such as `-v`, `add`, or `remove`.

### Requirements

Git  // Provides the `git remote` command.

### Representation

```bash
git remote -v
git remote add origin <url>
```
