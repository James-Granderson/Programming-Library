# `git fetch`

**Concept:** Git
**Action:** Fetch
**Object:** `git fetch`
**Classification:** Command
**Environment:** Git
**Path Type:** N/A
**Tags:** command

---

### What It Is

A Git command that downloads commits, files, and refs from a remote repository.

### What It Does

Updates local remote-tracking branches with the remote's latest data, without changing the current branch or working directory.

### How to Use

Run `git fetch` followed by the remote name to retrieve its latest data.

### Requirements

Git  // Provides the `git fetch` command.
Remote repository  // Supplies the data being fetched.

### Representation

```bash
git fetch origin
```
