# status

**Concept:** Git
**Action:** Display Status
**Object:** `git status`
**Classification:** Command
**Environment:** Git
**Path Type:** N/A
**Tags:** command

---

### What It Is

A Git command used to display the current state of the working directory and staging area.

### What It Does

Shows which files are modified, untracked, or staged for the next commit.

### How to Use

Run `git status` from inside a Git repository to see the current state of tracked and untracked files.

### Requirements

Git  // Provides the `git status` command.
Git repository  // Provides the repository whose status is displayed.

### Representation

```bash
git status
```
