# `git status`

**Concept:** Git
**Action:** Inspect
**Object:** `git status`
**Classification:** Command
**Environment:** Git
**Path Type:** N/A
**Tags:** command

---

### What It Is

A Git command that reports the current state of the working directory and staging area.

### What It Does

Shows which files are staged, unstaged, or untracked relative to the last commit.

### How to Use

Run `git status` from within a Git repository.

### Requirements

Git  // Provides the `git status` command.

### Representation

```bash
git status
```
