# `git init`

**Concept:** Git
**Action:** Initialize
**Object:** `git init`
**Classification:** Command
**Environment:** Git
**Path Type:** N/A
**Tags:** command

---

### What It Is

A Git command that creates a new, empty Git repository.

### What It Does

Creates a `.git` subdirectory containing the metadata Git needs to track version history.

### How to Use

Run `git init` inside the directory you want to turn into a repository.

### Requirements

Git  // Provides the `git init` command.

### Representation

```bash
git init
```
