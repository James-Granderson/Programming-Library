# `Pointer`

**Concept:** C
**Action:** Declare
**Object:** Pointer
**Classification:** Pointer Concept
**Environment:** Any C compiler
**Path Type:** N/A
---

---

### What It Is

A variable that stores the address of another object.

### What It Does

Holds a memory address so the program can access or modify the object at that location.

### How to Use

Declare a pointer by writing the pointee type, then `*`, then the pointer name.

### Requirements

C language  // Provides addressable objects and pointer types.

### Representation

```c
int x = 10;
int *p = &x;
```
