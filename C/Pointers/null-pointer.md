# null-pointer

**Concept:** C  
**Action:** Represent  
**Object:** Null Pointer  
**Classification:** Pointer Concept  
**Environment:** Any C compiler  
**Path Type:** N/A  

---

### What It Is

A pointer value that does not point to a valid object.

### What It Does

Indicates that a pointer currently points to no object.

### How to Use

Assign a null pointer constant to a pointer when it should point to no object.

### Requirements

`NULL`  // Provides a null pointer constant.

### Representation

```c
int *p = NULL;
