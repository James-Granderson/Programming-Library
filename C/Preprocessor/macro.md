# `macro`

**Concept:** C
**Action:** Define
**Object:** macro
**Classification:** Preprocessor Construct
**Environment:** Any C compiler
**Path Type:** N/A

---

### What It Is

A named substitution defined for the C preprocessor.

### What It Does

Replaces the macro name with its definition before the compiler processes the resulting code.

### How to Use

Define a macro with `#define` followed by its name and replacement.

### Requirements

`#define`  // Defines the macro name and its replacement.

### Representation

```c
#define PI 3.14159
