# `#define`

**Concept:** C
**Action:** Define
**Object:** `#define`
**Classification:** Preprocessor Directive
**Environment:** Any C compiler
**Path Type:** N/A

---

### What It Is

A preprocessor directive used to define a macro.

### What It Does

Tells the preprocessor to associate a name with replacement text before compilation.

### How to Use

Write `#define` followed by the macro name and its replacement.

### Requirements

Preprocessor  // Processes `#define` before compilation.

### Representation

```c
#define PI 3.14159
