### What It Is

A fixed-size sequence of values of the same type stored in contiguous memory.

### What It Does

Groups multiple values under one name and accesses each value by its zero-based index.

### How to Use

Declare an element type, a name, and a size in square brackets. Use square brackets with an index to read or assign an element.

### Requirements

C language  // Provides array declarations and indexing.

### Representation

```c
int scores[3] = {90, 85, 100};
int first_score = scores[0];
```
