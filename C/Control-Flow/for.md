# `for`

**Concept:** C
**Action:** Iterate
**Object:** `for`
**Classification:** Control Statement
**Environment:** Any C compiler
**Path Type:** N/A
**Tags:** keyword
---

---

### What It Is

A C control statement that repeats code while a condition remains true.

### What It Does

Runs an initializer, checks a condition before each iteration, and runs an update after each iteration.

### How to Use

Write `for`, then parentheses containing the initializer, condition, and update, followed by the loop body.

### Requirements

C language  // Provides loop execution.

### Representation

```c
for (int i = 0; i < 10; i++) {
    printf("%d\n", i);
}
```
