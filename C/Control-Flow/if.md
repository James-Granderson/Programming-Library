# `if`

**Concept:** C
**Action:** Branch
**Object:** `if`
**Classification:** Control Statement
**Environment:** Any C compiler
**Path Type:** N/A
**Tags:** keyword
---

---

### What It Is

A C control statement that runs code only when a condition is true.

### What It Does

Evaluates a condition and executes the attached statement or block when the result is non-zero.

### How to Use

Write `if`, the condition in parentheses, then the statement or block to run when the condition is true.

### Requirements

C language  // Evaluates conditions and controls statement execution.

### Representation

```c
if (x > 0) {
    printf("positive\n");
}
```
