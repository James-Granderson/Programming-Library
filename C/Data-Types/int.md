# int

**Concept:** C
**Action:** Declare
**Object:** `int`
**Classification:** Data Type

### What It Is

A built-in C data type used to represent integer values.

### What It Does

Stores whole-number values without a fractional component.

### How to Use

Declare a variable with the `int` type and optionally initialize it with an integer value.

### Requirements

C language  // `int` is a built-in C data type.
