# `short`
**Concept:** C
**Action:** Declare
**Object:** `short`
**Classification:** Data Type
**Environment:** Any C compiler
**Path Type:** N/A
**Tags:** keyword
---

---

### What It Is

An integer data type used to store whole numbers.

### What It Does

Stores signed whole-number values. It is guaranteed to be at least 16 bits.

### How to Use

Declare a variable with `short`.

### Requirements

None.

### Representation

```c
short number = 42;
```
