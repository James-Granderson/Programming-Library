# `long long`
**Concept:** C
**Action:** Declare
**Object:** `long long`
**Classification:** Data Type
**Environment:** Any C compiler
**Path Type:** N/A
**Tags:** keyword

---

### What It Is

An integer data type used to store whole numbers.

### What It Does

Stores signed whole-number values. It is guaranteed to be at least 64 bits.

### How to Use

Declare a variable with `long long`.

### Requirements

None.

### Representation

```c
long long population = 8000000000LL;
```
