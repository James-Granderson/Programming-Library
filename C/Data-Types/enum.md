# `enum`

**Concept:** C
**Action:** Define
**Object:** `enum`
**Classification:** Data Type
**Environment:** Any C compiler
**Path Type:** N/A
**Tags:** keyword

---

### What It Is

A C keyword used to define a set of named integer constants.

### What It Does

Creates an enumerated type whose members map to integer values.

### How to Use

Write `enum` followed by a tag name and a comma-separated list of enumerators inside braces.

### Requirements

C language  // `enum` defines an enumerated type.

### Representation

```c
enum Color {
    RED,
    GREEN,
    BLUE
};
```
