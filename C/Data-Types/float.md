### What It Is

A built-in C data type used to store single-precision floating-point values.

### What It Does

Represents numbers with a fractional component using limited precision.

### How to Use

Declare a variable with the `float` type and optionally initialize it with a floating-point literal.

### Requirements

C language  // `float` is a built-in C data type.

### Representation

```c
float price = 19.99f;
```
