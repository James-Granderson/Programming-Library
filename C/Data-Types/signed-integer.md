# `signed int`

**Concept:** C
**Action:** Declare
**Object:** `signed int`
**Classification:** Data Type
**Environment:** Any C compiler
**Path Type:** N/A
**Tags:** keyword

---

### What It Is

A signed integer type that can represent negative, zero, and positive whole-number values.

### What It Does

Stores integer values using the same signedness as the default `int` type.

### How to Use

Write `signed int` before a variable name and optionally initialize it with a whole-number value.

### Requirements

C language  // Provides the `signed` and `int` type specifiers.

### Representation

```c
signed int temperature = -12;
```
