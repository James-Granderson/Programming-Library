# `long`
**Concept:** C
**Action:** Declare
**Object:** `long`
**Classification:** Data Type
**Environment:** Any C compiler
**Path Type:** N/A
**Tags:** keyword
---

---

### What It Is

An integer data type used to store whole numbers.

### What It Does

Stores signed whole-number values. Its size is implementation-dependent, but it is guaranteed to be at least 32 bits.

### How to Use

Declare a variable with `long`.

### Requirements

None.

### Representation

```c
long population = 8000000000L;
```
