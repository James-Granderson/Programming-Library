# struct

**Concept:** C
**Action:** Define
**Object:** `struct`
**Classification:** Data Type
**Environment:** Any C compiler
**Path Type:** N/A

---

### What It Is

A C keyword used to define a user-defined data type.

### What It Does

Groups related data members into a single type.

### How to Use

Write `struct` followed by a structure name and its members.

### Requirements

C language  // `struct` is used to define a user-defined data type.

### Representation

```c
struct Person {
    int age;
};
