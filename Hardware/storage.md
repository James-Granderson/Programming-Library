Classification: Persistent Storage
Environment: Computer
Path Type: N/A
Tags: storage, data, hardware

What It Is

Storage is hardware used to retain data persistently.

What It Does

Storage holds operating systems, applications, files, and other data when the computer is powered off.

How to Use

The operating system reads data from storage into memory and ws data back to storage.

Requirements

A storage device and storage interface.

Representation
Storage ↔ RAM ↔ CPU
