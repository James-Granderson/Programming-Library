
File Storage

Concept: File Storage
Action: Persist
Object: File
Classification: Storage System
Environment: Computer
Path Type: Filesystem
Tags: file, storage, filesystem,hat It Is

File storage is the organization of persistent data into named files managed by a filesystem.

What It Does

It maps logical files to physical or logical storage locations.

How to Use

Programs access files through filesystem operations rather than directly manipulating individual storage cells.

Requirements

Storage device and filesystem.

Representation
File → Filesystem → Blocks → Storage Device
