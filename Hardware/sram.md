
SRAM

Concept: SRAM
Action: Store
Object: Bit
Classification: Memory Technology
Environment: CPU
Path Type: N/A
Tags: sram, cache, memory, hardware

What It Is

Static Random Access Memory (SRAM) stores bits using transistor-based circuits.

What It Does

SRAM provides very fast memory access without the periodic refresh required by DRAM.

How to Use

SRAM is commonly used for CPU cache.

Requirements

Transistor-based memory cells and supporting circuitry.

Representation
SRAM → Cache → CPU
