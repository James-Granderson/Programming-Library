
L3 Cache

Concept: L3 Cache
Action: Cache
Object: Data
Classification: CPU Cache
Environment: CPU
Path Type: N/A
Tags: l3, cache, cpu, memory

What It Is

L3 cache is a larger cache level generally positioned between L2 cache and main memory.

What It Does

It provides a shared or larger pool of fast memory before the system must access RAM.

How to Use

The processor can search L3 after an L1 and L2 cache miss.

Requirements

CPU architecture with L3 cache.

Representation
CPU → L1 → L2 → L3 → RAM
