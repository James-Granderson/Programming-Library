What It Is

A block is a logical unit of storage used by filesystems and storage systems.

What It Does

Blocks divide persistent storage into manageable units.

How to Use

Filesystems allocate blocks to store file data and metadata.

Requirements

Storage device and filesystem or storage-management system.
