
Hard Disk Drive

Concept: Hard Disk Drive
Action: Persist
Object: Data
Classification: Storage Device
Environment: Computer
Path Type: N/A
Tags: hdd, hard-disk, storage, hardware

What It Is

A hard disk drive (HDD) stores data magnetically on rotating platters.

What It Does

A read/write head detects and changes magnetic states on the storage media.

How to Use

The computer communicates with the HDD through a storage interface and controller.

Requirements

Magnetic platters, read/write heads, motor, controller electronics, and interface.

Representation
Data → Controller → Read/Write Head → Magnetic Platter
