What It Is

A GPU (Graphics Processing Unit) is a processor designed to perform large numbers of operations in parallel.

What It Does

Processes graphics and other workloads that can be divided into many parallel operations.

How to Use

Software sends work to the GPU through graphics and compute interfaces, and the GPU processes that work using its many processing units.
