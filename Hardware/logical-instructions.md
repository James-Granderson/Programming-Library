
Logical Instructions

Concept: Logical Instruction
Action: Manipulate
Object: Bits
Classification: CPU Instruction
Environment: CPU
Path Type: N/A
Tags: instruction, logic, bitwise, cpu

What It Is

A logical instruction performs a Boolean or bitwise operation on data.

What It Does

Common operations include:

AND
OR
XOR
NOT
SHL
SHR
How to Use

Example:

AND R1, R2

The operation is applied to the corresponding bits of the operands.

Requirements

A CPU architecture with logical instructions.

Representation
Registers → Logic Operation → Result
