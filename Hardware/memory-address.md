
Memory Address

Concept: Memory Address
Action: Identify
Object: Memory Location
Classification: Address
Environment: Computer
Path Type: N/A
Tags: address, memory, cpu, hardware

What It Is

A memory address identifies a location in memory.

What It Does

The CPU uses addresses to specify where data should be read or written.

How to Use

An address is supplied as part of a memory access.

Requirements

Addressable memory and a defined addressing system.

Representation
Address → Memory Location → Value
