
Solid State Drive

Concept: Solid State Drive
Action: Persist
Object: Data
Classification: Storage Device
Environment: Computer
Path Type: N/A
Tags: ssd, storage, flash, hardwareIs

A solid-state drive (SSD) is persistent storage that stores data electronically.

What It Does

An SSD stores data in non-volatile flash memory and uses a controller to manage that storage.

How to Use

The computer communicates with an SSD through an interface such as SATA or NVMe.

Requirements

Flash memory, storage controller, and compatible interface.

Representation
Data → SSD Controller → Flash Memory
