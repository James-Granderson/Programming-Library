
Cache Miss

Concept: Cache Miss
Action: Retrieve
Object: Uncached Data
Classification: Memory Access
Environment: CPU
Path Type: N/A
Tags: cache, miss, memory, cpu

What It Is

A cache miss occurs when requested data is not present in the relevant cache.

What It Does

The system retrieves the data from a lower level of memory.

How to Use

A miss causes the processor to search lower cache levels or main memory.

Requirements

A functioning memory hierarchy.

Representation
CPU Request → Cache → Miss → Lower Memory Level
