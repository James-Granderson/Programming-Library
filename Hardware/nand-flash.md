
NAND Flash

Concept: NAND Flash
Action: Store
Object: Bit
Classification: Non-Volatile Memory
Environment: Storage
Path Type: N/A
Tags: nand, flash, ssd, storage, memory

What It Is

NAND flash is a type of non-volatile memory used for persistent electronic storage.

What It Does

NAND flash stores information by controlling electrical charge in memory cells.

How to Use

NAND flash is organized into arrays and managed by storage controllers.

Requirements

Flash memory cells and controller hardware.

Representation
Bit → Flash Cell → Flash Array
