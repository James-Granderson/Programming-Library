
L2 Cache

Concept: L2 Cache
Action: Cache
Object: Data
Classification: CPU Cache
Environment: CPU
Path Type: N/A
Tags: l2, cache, cpu, memory

What It Is

L2 cache is a larger cache level below L1.

What It Does

It provides more cached data while remaining faster than main memory.

How to Use

The processor consults L2 when requested data is not found in L1.

Requirements

CPU cache hardware.

Representation
CPU → L1 → L2 → L3 → RAM
