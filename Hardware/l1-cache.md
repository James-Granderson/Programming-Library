
L1 Cache

Concept: L1 Cache
Action: Cache
Object: Data
Classification: CPU Cache
Environment: CPU
Path Type: N/A
Tags: l1, cache, cpu, memory

What It Is

L1 cache is the smallest and only used cache level closest to the CPU execution units.

What It Does

It provides very fast access to frequently needed instructions and data.

How to Use

The processor automatically uses L1 cache during execution.

Requirements

CPU cache hardware.

Representation
CPU → L1 Cache → L2 Cache
