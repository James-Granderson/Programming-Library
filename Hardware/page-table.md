
Page Table

Concept: Page Table
Action: Map
Object: Virtual Page
Classification: Memory Management Structure
Environment: Operating System
Path Type: N/A
Tags: page-table, virtual-memory, memory, address

What It Is

A page table stores mappings between virtual pages and physical memory frames.

What It Does

It allows virtual addresses to be translated intoses.

How to Use

The processor's memory-management hardware consults page-table information during address translation.

Requirements

Virtual memory and operating-system memory management.

Representation
Virtual Page → Page Table → Physical Frame
