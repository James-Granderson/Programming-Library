Path Type: N/A
Tags: decoder, logic, instruction, hardware

What It Is

A decoder converts an encoded input into one or more distinct output signals.

What It Does

A decoder can activate a specific output based on a binary input.

How to Use

Decoders are used to identify or select hardware states.

Requirements

Logic gates and binary input signals.

Representation
Binary Input → Decoder → Selected Output
