
Storage Controller

Concept: Storage Controller
Action: Manage
Object: Storage Device
Classification: Controller
Environment: Computer Hardware
Path Type: N/A
Tags: storage-controller, ssd, hdd, storage, hardware

What It Is

A storage controller manages communication between the computer and a storage device.

What It Does

It translates storage requests into operations appropriate for the underlying device.

How to Use

The operating system sends storage requests through the system's storage intce.

Requirements

Compatible controller and storage device.

Representation
CPU / OS → Storage Controller → SSD / HDD
