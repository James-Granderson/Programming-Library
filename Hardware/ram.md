What It Is

Random Access Memory (RAM) is the computer's primary working memory.

What It Does

RAM holds instructions and data needed while programs are running.

RAM is generally volatile, meaning its contents are lost when power is removed.

How to Use

The operating system and applications use RAM as working storage.

Requirements

Compatible RAM hardware and memory controller.

Representation
Storage → RAM → CPU
