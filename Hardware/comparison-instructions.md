
Comparison Instructions

Concept: Comparison Instruction
Action: Compare
Object: Values
Classification: CPU Instruction
Environment: CPU
Path Type: N/A
Tags: instruction, comparisonpu

What It Is

A comparison instruction evaluates a relationship between values.

What It Does

A comparison can determine whether values are equal, unequal, greater, or less.

It commonly updates CPU flags.

How to Use

Example:

CMP R1, R2

Conceptually:

R1 compared with R2
        ↓
      Flags
Requirements

A CPU architecture with comparison or equivalent instructions.

Representation
Values → Compare → Flags
