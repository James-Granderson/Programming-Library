
Memory Bus

Concept: Memory Bus
Action: Transfer
Object: Memory Information
Classification: Interconnect
Environment: Compuware
Path Type: N/A
Tags: memory-bus, bus, ram, cpu

What It Is

A memory bus is an interconnect used to transfer information between the processor or memory controller and memory.

What It Does

It carries signals involved in memory operations.

How to Use

Memory hardware communicates through the electrical interfaces defined by the platform.

Requirements

Compatible memory controller and memory hardware.

Representation
CPU / Controller ↔ Memory Bus ↔ RAM
