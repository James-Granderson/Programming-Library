What It Is

A cache is a small, fast memory that stores copies of data likely to be needed soon.

What It Does

Caching reduces the time the CPU spends waiting for data from slower memory.

How to Use

Modern processors automatically manage multiple cache levels such as L1, L2, and L3.

Requirements

Fast memory and cache-control mechanisms.

Representation
CPU → L1 → L2 → L3 → RAM
