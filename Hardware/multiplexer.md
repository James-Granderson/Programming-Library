
Multiplexer

Action: Select
Object: Input
Classification: Combinational Circuit

Path Type: N/A
Tags: multiplexer, mux, selection, hardware

What It
A multiplexer selects one input from multiple inputs and sends it to an output.

What It Does

Selection signals determine which input reaches the output.

How to Use

Multiplexers allow digital circuits to select between different data sources.

Requirements

Logic gates and selection signals.
