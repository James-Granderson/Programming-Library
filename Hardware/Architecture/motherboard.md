### What It Is

A motherboard is the main printed circuit board that mechanically mounts and electrically connects a computer's processor, memory, expansion devices, storage interfaces, and power delivery. Exact components and integration vary across desktops, laptops, and embedded systems.

### What It Does

It distributes power and provides communication paths, sockets, firmware interfaces, and connectors among system components. It does not itself perform all computing; installed processors and devices provide most functions.

### How to Use

1. Check CPU socket, memory type, and firmware support before choosing parts.
2. Install compatible components and connect required power and data cables.
3. Use the board manual to identify slots, headers, and firmware settings.

### Requirements

Compatible components, correct power connections, and firmware support are required. Form factor, sockets, and supported capabilities are board-specific.

CPU ↔ chipset/interconnect ↔ RAM / storage / expansion; PSU → board power rails
