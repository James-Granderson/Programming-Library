
Page

Action: Divide
Object: Virtual Memory
Classification: Memory Unit
Environment: Computer
Path Type: N/A
Tags: page, virtual-memory, memory, ram

What It Is

A page is a fixed-size block of virtual memory.

What It Does

Pages divide virtual address spaces into manageable units.

How to Use

Virtual addresses are interpreted as a page number plus an offset within that page.

Requirements

Virtual memory system.

Representation
Virtual Address
├── Page Number
└── Page Offset
