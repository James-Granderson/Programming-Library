What It Is

The program counter is a CPU register that tracks the memory address of the next instruction to be fetched.

What It Does

Tells the CPU  instruction during sequential execution.

How to Use

The CPU automatically updates the program counter as instructions execute. Branches and jumps can change it to a different address.
