# `Stack`

**Concept:** Data Structures
**Action:** Store
**Object:** Stack
**Classification:** Data Structure
**Environment:** Language-independent
**Path Type:** N/A
**Tags:** data-structure

---

### What It Is

A last-in, first-out collection.

### What It Does

Adds and removes values only at the top.

### How to Use

Push values onto the top and pop the most recently pushed value.

### Representation

```text
top → [ newest, ..., oldest ]
```
