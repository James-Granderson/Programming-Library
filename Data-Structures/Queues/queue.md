# `Queue`

**Concept:** Data Structures
**Action:** Store
**Object:** Queue
**Classification:** Data Structure
**Environment:** Language-independent
**Path Type:** N/A
**Tags:** data-structure

---

### What It Is

A first-in, first-out collection.

### What It Does

Adds values at the rear and removes values from the front.

### How to Use

Enqueue at the rear and dequeue from the front.

### Representation

```text
front → [ oldest, ..., newest ] ← rear
```
