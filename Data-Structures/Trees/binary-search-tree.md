### What It Is

A binary tree where smaller keys are stored left of a node and larger keys right of it.

### What It Does

Organizes ordered keys for search, insertion, and removal.

For every node N, every key in N's left subtree is smaller than N's key, and every key in N's right subtree is larger. This holds recursively at every node, not just the root.

### How to Use

Compare a key at each node and continue into the left or right subtree.

### Representation

```
        8
       / \
      3   10
     / \    \
    1   6    14
       / \   /
      4   7 13
```
