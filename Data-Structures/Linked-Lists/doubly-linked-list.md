# doubly-linked-list

**Concept:** Data Structures
**Action:** Store
**Object:** Doubly Linked List
**Classification:** Data Structure
**Environment:** Language-independent
**Path Type:** N/A
**Tags:** data-structure

---

### What It Is

A linked list whose nodes link to both next and previous nodes.

### What It Does

Supports traversal in either direction.

### How to Use

Maintain both links whenever inserting or removing a node.

### Representation

```text
null ← [ previous | value | next ] ⇄ [ previous | value | next ] → null
```
