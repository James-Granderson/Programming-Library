# `Linked List`

**Concept:** Data Structures
**Action:** Store
**Object:** Linked List
**Classification:** Data Structure
**Environment:** Language-independent
**Path Type:** N/A
**Tags:** data-structure

---

### What It Is

A sequence of nodes that each link to the next node.

### What It Does

Stores ordered values without requiring contiguous storage.

### How to Use

Keep a reference to the first node and follow links until the end.

### Representation

```text
head → [ value | next ] → [ value | next ] → null
```
