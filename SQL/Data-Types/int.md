# `INT`

**Concept:** SQL
**Action:** Declare
**Object:** `INT`
**Classification:** Data Type
**Environment:** Any SQL database
**Path Type:** N/A
**Tags:** keyword

---

### What It Is

A SQL data type used to store integer values.

### What It Does

Represents whole-number values in a column definition.

### How to Use

Specify `INT` as the column type when creating or altering a table.

### Requirements

SQL database  // Processes column definitions that use `INT`.

### Representation

```sql
CREATE TABLE users (
    id INT,
    age INT
);
```
