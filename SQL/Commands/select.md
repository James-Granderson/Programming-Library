# `SELECT`

**Concept:** SQL
**Action:** Query
**Object:** `SELECT`
**Classification:** Statement
**Environment:** Any SQL database
**Path Type:** N/A
**Tags:** keyword

---

### What It Is

A SQL statement used to retrieve data from one or more tables.

### What It Does

Reads columns from a table and returns the matching rows as a result set.

### How to Use

Write `SELECT` followed by the column names or `*`, then `FROM` and the table name.

### Requirements

SQL database  // Provides tables and executes `SELECT` statements.

### Representation

```sql
SELECT name, age FROM users;
```
