### What It Is

The Central Processing Unit (CPU) is the primary component that executes machine instructions.

It reads instructions, performs operations, moves data, and controls the sequence in which instructions are executed.

### What It Does

The CPU repeatedly processes instructions from a program.

At a basic level, it:

1. Gets an instruction.
2. Determines what the instruction means.
3. Performs the required operation.
4. Moves to the next instruction.

### How to Use

Programs are executed by a CPU when the operating system loads their machine instructions for execution.
