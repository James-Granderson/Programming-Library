What It Is

The instruction register (IR) is a CPU register that holds the current instruction being processed.

What It Does

After the CPU fetches an instruction from memory, the instruction can be placed into the instruction register.

The CPU's control logic tes the instruction to determine what operation needs to be performed.

How to Use

The CPU manages the instruction register automatically during instruction execution.

Requirements

A CPU architecture that uses an instruction register or an equivalent mechanism.
