What It Is

The program counter (PC) is a CPU register that tracks the location of the next instruction to be executed.

Whrogram counter when fetching instructions from memory.

Normally, the program counter advances to the next instruction after an instruction is fetched.

Control-flow instructions such as jumps and branches can change the program counter to a different location.

How to Use

The CPU automatically updates the program counter as it executes a program.

Requirements

A CPU architecture with a program counter.
