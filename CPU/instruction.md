### What It Is

An instruction is a machine-level command that tells the CPU what operation to perform.

An instruction specifies an operation and, when necessary, the data or locations involved in that operation.

### What It Does

An instruction can tell the CPU to perform operations such as:

- Add values.
- Move data.
- Compare values.
- Load data from memory.
- Store data in memory.
- Jump to another instruction.

### How to Use

Instructions are encoded according to the instruction set of a particular CPU architecture.

### Requirements

A CPU architecture with a defined instruction set.
