What It Is

The arithmetic logic unit (ALU) is the part of the CPU that performs arithmetic and logical operations.

What It Does

The ALU can perform operations such as:

Addition.
Subtraction.
Bitwise AND.
Bitwise OR.
Bitwise XOR.
Comparisons.
Bit shifts.

The exact operations available depend on the CPU architecture.

How to Use

The control unit directs the ALU to perform the operation specified by an instruction.

Reents

A CPU architecture containing an arithmetic and logic execution mechanism.
