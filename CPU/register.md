What It Is

A register is a small, peed storage location inside the CPU.

Registers hold values that the CPU needs while executing instructions.

What It Does

Registers can hold:

Data values.
Addresses.
Instructions.
The location of the next instruction.
Status information.

Examples include general-purpose registers, the program counter, the instruction register, and status registers.

How to Use

Instructions read from and write to registers as part of their execution.

Requirements

A CPU architecture that defines registers.
