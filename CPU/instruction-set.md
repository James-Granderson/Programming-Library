What It Is

An instruction set is the collection of machine instructions that a CPU architecture understands.

It forms the interface between software and the processor.

What It Does

An instruction set defines things such as:

Which instructions exist.
Which registers are available.
Which operands instructions can use.
Which data types are supported.
How instructions are encoded.
How memory can be addressed.
How to Use

Software is compiled or assembled into instructions that conform to the target CPU's instruction set.

Requirements

A CPU architecture with a defined instruction set.
