# `Operators`

**Concept:** Operations
**Action:** Operate
**Object:** `Operands`
**Classification:** Operator
**Environment:** Python Runtime
**Path Type:** Direct
**Tags:** operators, arithmetic, comparison, special methods

---

### What It Is

Operators are syntax for operations. Many operators connect to special methods on objects.

### What It Does

They combine, compare, transform, or test objects.

### How to Use

Use arithmetic, comparison, boolean, membership, identity, and bitwise operators according to the objects involved.

### Requirements

Operands must support the requested operation.

### Representation

```python
print(2 + 3)
print("a" + "b")
print(3 in [1, 2, 3])
|Operator syntax often hides a protocol call. That is important when learning custom objects.
```
