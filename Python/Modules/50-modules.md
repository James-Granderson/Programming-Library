# `Modules`

**Concept:** Code Organization
**Action:** Organize
**Object:** `Python Code`
**Classification:** Module
**Environment:** Python Import System
**Path Type:** Direct
**Tags:** module, .py, namespace, import

---

### What It Is

A module is a Python source file that provides a namespace containing definitions and module-level execution.

### What It Does

It separates code and gives names a reusable namespace boundary.

### How to Use

Create a .py file and import it from another module.

### Requirements

The import system must locate the module.

### Representation

```python
import math
print(math.sqrt(16))
|Modules are namespace boundaries as much as they are files.
```
