# `Syntax and Literals`

**Concept:** Syntax
**Action:** Write
**Object:** `Python source`
**Classification:** Language Construct
**Environment:** Python 3.x
**Path Type:** Direct
**Tags:** syntax, literals, indentation, grammar

---

### What It Is

Python source is parsed into statements and expressions. Indentation is part of Python block structure, and literals directly describe values.

### What It Does

It gives the parser structure and gives programmers compact ways to express values.

### How to Use

Learn indentation, delimiters, literals, comments, and the distinction between expressions and statements.

### Requirements

Valid Python grammar and consistent indentation.

### Representation

```python
items = [1, 2, 3]
name = "James"
|Syntax is the surface. The runtime model underneath it is where the deeper understanding lives.
```
