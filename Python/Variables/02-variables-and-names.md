# `Variables and Names`

**Concept:** Names
**Action:** Bind
**Object:** `Objects`
**Classification:** Name Binding
**Environment:** Python Runtime
**Path Type:** Direct
**Tags:** variables, names, binding, references

---

### What It Is

A Python variable is a name bound to an object. The name can later be rebound to another object.

### What It Does

It gives programs a way to associate meaningful names with runtime objects.

### How to Use

Use assignment and reason about which object the name currently reaches.

### Requirements

A namespace must exist for the binding.

### Representation

```python
x = 42
x = "hello"
|Think name -> object, not variable -> box.
```
