# `Objects`

**Concept:** Object Model
**Action:** Represent
**Object:** `Values`
**Classification:** Runtime Entity
**Environment:** Python Runtime
**Path Type:** Direct
**Tags:** objects, identity, type, value

---

### What It Is

Python operates on objects. An object has identity, type, and state or value.

### What It Does

Objects provide the runtime behavior on which operations are performed.

### How to Use

Use type(), identity tests, attributes, and operations to investigate objects.

### Requirements

The object must exist.

### Representation

```python
x = [1, 2, 3]
print(type(x))
```
