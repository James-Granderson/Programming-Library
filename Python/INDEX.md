### What It Is

A connected map of Python from its runtime object model through syntax, collections, functions, iteration, object-oriented programming, polymorphism, protocols, exceptions, I/O, typing, concurrency, tooling, and advanced runtime behavior.

### What It Does

It turns the folder into a searchable conceptual library rather than a pile of isolated definitions.

### How to Use

Follow the numbered entries, but jump freely when a concept becomes relevant. The intended route is objects and names -> functions -> collections -> iteration -> classes -> polymorphism -> protocols -> runtime -> I/O -> typing -> concurrency -> tooling.

### Requirements

Python 3.x and a terminal.

### Representation

```text
Objects -> Names -> Types -> Functions -> Collections -> Iteration -> OOP -> Polymorphism -> Protocols -> Runtime -> I/O -> Typing -> Concurrency -> Tooling
```
