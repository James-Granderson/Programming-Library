# `Functions`

**Concept:** Callable Abstraction
**Action:** Call
**Object:** `Arguments`
**Classification:** Function
**Environment:** Python Runtime
**Path Type:** Direct
**Tags:** functions, def, return, first-class

---

### What It Is

A function is a callable object containing reusable behavior. Functions can be passed, stored, and returned.

### What It Does

A call creates an execution context, binds parameters, executes the body, and produces a result.

### How to Use

Define with def and use return to produce results.

### Requirements

Arguments must satisfy the signature.

### Representation

```python
def add(a, b):
    return a + b

result = add(2, 3)
|Functions are objects, which is why higher-order programming works naturally in Python.
```
