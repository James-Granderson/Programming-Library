# `Lambda Functions`

**Concept:** Callable Expression
**Action:** Create
**Object:** `Callable`
**Classification:** Anonymous Function
**Environment:** Python Runtime
**Path Type:** Direct
**Tags:** lambda, anonymous function, sort key

---

### What It Is

A lambda is a small anonymous function defined as an expression.

### What It Does

It provides concise local behavior.

### How to Use

Use it for small transformations such as sort keys; use def for substantial logic.

### Requirements

A lambda contains one expression.

### Representation

```python
names.sort(key=lambda name: len(name))
|Anonymous does not mean mysterious; it is simply unnamed callable behavior.
```
