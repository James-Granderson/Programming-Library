# `Dictionaries`

**Concept:** Mapping
**Action:** Map
**Object:** `Keys to Values`
**Classification:** Hash Mapping
**Environment:** Python Runtime
**Path Type:** Direct
**Tags:** dict, mapping, keys, values, hash table

---

### What It Is

A dictionary maps hashable keys to values and preserves insertion order in modern Python.

### What It Does

It provides direct lookup by key and represents labeled associations naturally.

### How to Use

Use indexing, get, items, keys, values, update, and comprehensions.

### Requirements

Keys must be hashable.

### Representation

```python
prices = {"apple": 2.5}
prices["pear"] = 3.0
|Dictionary reasoning becomes powerful when keys are treated as explicit labels.
```
