# `Tuples`

**Concept:** Sequence
**Action:** Group
**Object:** `Values`
**Classification:** Immutable Collection
**Environment:** Python Runtime
**Path Type:** Direct
**Tags:** tuple, unpacking, immutable sequence

---

### What It Is

A tuple is an ordered immutable sequence. Its elements can still refer to mutable objects.

### What It Does

It provides stable grouping and convenient unpacking.

### How to Use

Use tuples for fixed structural groupings and multiple-return-value patterns.

### Requirements

The tuple structure cannot be changed after creation.

### Representation

```python
point = (10, 20)
x, y = point
|Tuple immutability concerns the tuple structure, not necessarily the objects it contains.
```
