# `Lists`

**Concept:** Sequence
**Action:** Store
**Object:** `Ordered Values`
**Classification:** Mutable Collection
**Environment:** Python Runtime
**Path Type:** Direct
**Tags:** list, indexing, slicing, append, sort

---

### What It Is

A list is a mutable ordered sequence containing arbitrary Python objects.

### What It Does

It provides indexing, slicing, insertion, deletion, sorting, and iteration.

### How to Use

Use append, extend, insert, remove, pop, sort, and indexing as appropriate.

### Requirements

Indexes and method arguments must be valid.

### Representation

```python
items = ["a", "b"]
items.append("c")
|Lists are flexible but mutation can create aliasing surprises.
```
