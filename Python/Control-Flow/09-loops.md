# `Loops`

**Concept:** Iteration Control
**Action:** Repeat
**Object:** `Statements`
**Classification:** Loop
**Environment:** Python Runtime
**Path Type:** Control-Flow
**Tags:** for, while, break, continue

---

### What It Is

for consumes an iterable while while repeats while a condition remains true.

### What It Does

They express repeated work and traversal.

### How to Use

Prefer for for collection traversal and while for condition-driven repetition.

### Requirements

for requires an iterable; while requires an evaluable condition.

### Representation

```python
for item in items:
    print(item)

while running:
    step()
|Loop behavior is easier to understand when you identify the state that changes each iteration.
```
