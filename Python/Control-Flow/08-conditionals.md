# `Conditionals`

**Concept:** Control Flow
**Action:** Select
**Object:** `Execution Path`
**Classification:** Branching
**Environment:** Python Runtime
**Path Type:** Control-Flow
**Tags:** if, elif, else, branching

---

### What It Is

Conditionals select among execution paths based on evaluated conditions.

### What It Does

They make alternative behavior explicit.

### How to Use

Use if, elif, and else with clear conditions.

### Requirements

Conditions must be valid expressions.

### Representation

```python
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"
|Branching is a decision point in the program's causal chain.
```
