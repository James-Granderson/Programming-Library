# Tags

Controlled list of tags used across entries. Check here before inventing
a new one — reuse an existing tag if it already fits.

Use tags to unify related entries across Concepts for search — the mirror of
Concept/Object keys, which disambiguate identical names (`C/NULL` vs `SQL/NULL`).

`keyword` and `operator` are mutually exclusive at the token level. A token
is one or the other, not both. Other tags (e.g. matching Classification) may
combine with either.
