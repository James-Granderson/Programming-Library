A Universal Programming Library

Stored here are general programming concepts and lessons.

These lessons are assorted and arranged by a schema kept up to date by Hypsos. 

Hypsos is the automation layer for the library.

Its purpose is to maintain the database mechanically: checking entries against the schema, detecting missing vocabulary, enforcing structural rules, and automating repetitive library maintenance.

The library should be able to maintain itself as it grows

As objects can be re-used multiple times, ownership is explicitly handled by explicit schema:
Concept
Action 
Object
Classification 
Environment
Path 
Type
Tags

The goal is fast lookups, and knowledge endowed to the individual by virtue of the questions they might have to ask in real time.

Therefore, if you want to know how to search through this library, just ask us, and look it up.

Our Philosophy

The fundamental idea:

Understand the thing first from top down heirarchically. Then represent it and reconstruct it.

Programming becomes much easier when the underlying reality is understood in plain English before translating that reality into syntax.

The library is therefore built from the outside in:

Reality
↓
Concept
↓
Relationship
↓
Representation
↓
Code

The objective is to develop a connected mental model of computing rather than memorize isolated syntax.

Status

This is an actively evolving personal knowledge base. Structure, schemas, concepts, and automation will continue to change as the library develops.
