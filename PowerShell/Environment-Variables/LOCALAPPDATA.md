# LOCALAPPDATA

**Concept:** PowerShell
**Action:** Access Path
**Object:** `$env:LOCALAPPDATA`
**Classification:** Environment Variable
**Environment:** PowerShell
**Path Type:** Local Application Data
**Tags:** environment-variable

---

### What It Is

An environment variable containing the path to the user's local application data directory.

### What It Does

Provides the path to a location for user-specific application data.

### How to Use

Access the variable with `$env:LOCALAPPDATA` in PowerShell.

### Requirements

PowerShell // Provides access to environment variables through `$env:`.

### Representation

```powershell
$env:LOCALAPPDATA
```
