# `Get-ChildItem`

**Concept:** PowerShell
**Action:** List
**Object:** `Get-ChildItem`
**Classification:** Cmdlet
**Environment:** PowerShell
**Path Type:** N/A
**Tags:** cmdlet
---

---

### What It Is

A PowerShell cmdlet for retrieving items from a specified location.

### What It Does

Returns the files and directories contained in the specified location.

### How to Use

Run `Get-ChildItem`, optionally with a path, to list its contents.

### Requirements

PowerShell // Cmdlets are the native command type in the PowerShell environment.

### Representation

```powershell
Get-ChildItem
```
