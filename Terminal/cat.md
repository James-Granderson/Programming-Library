# `cat`

**Concept:** Shell  
**Action:** Display  
**Object:** `cat`  
**Classification:** Command  
**Environment:** Shell  
**Path Type:** N/A  
**Tags:** command

---

### What It Is

A shell command that reads and outputs files.

### What It Does

Writes the conmore files to standard output.

### How to Use

Run `cat` followed by one or more file paths.

### Requirements

Shell

### Representation

```sh
cat file.txt

```

Flags

```text
-n — Number all output lines.
-b — Number only non-blank lines.
-s — Squeeze repeated blank lines into one.
-A — Show non-printing characters and line endings explicitly.

```
