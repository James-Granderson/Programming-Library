---

### What It Is

A shell command that counts properties of text input.
### What It Does

Counts lines, words, bytes, or characters in files or standard input.
### How to Use

Run wc followed by optional flags and one or more files.
### Requirements

Shell
### Representation
wc -l file.txt
Flags
-l — Count lines.
-w — Count words.
-c — Count bytes.
-m — Count characters.
