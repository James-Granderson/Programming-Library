# `echo`

**Concept:** Shell
**Action:** Print
**Object:** echo
**Classification:** Command
**Environment:** Shell
**Path Type:** N/A
**Tags:** command

---

### What It Is

A shell command or builtin used to write text to standard output.
### What It Does

Prints its arguments followed by a newline by default.
### How to Use

Run echo followed by the text to display.
### Requirements

Shell
### Representation
```sh
echo "hello"

```
Flags
```text
-n — Suppress the trailing newline.
-e — Enable interpretation of backslash escapes on implementations that support this behavior.
```
