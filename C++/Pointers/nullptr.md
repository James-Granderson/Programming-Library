# `nullptr`

**Concept:** `C++`
**Action:** Assign Value
**Object:** `nullptr`
**Classification:** Null Pointer Literal
**Environment:** Any `C++11` or later compiler
**Path Type:** N/A
**Tags:** keyword, expression
---

---

### What It Is

A null pointer literal built into `C++`.

### What It Does

Represents a null pointer value without being a pointer itself.

### How to Use

Assign `nullptr` to a pointer when it should point to no object.

### Requirements

`C++11`  // Introduced `nullptr` as a built-in null pointer literal.

### Representation

```cpp
int *p = nullptr;
```
