# `std::string`

**Concept:** `C++`
**Action:** Declare
**Object:** `std::string`
**Classification:** Data Type
**Environment:** Any `C++` compiler
**Path Type:** N/A
---

---

### What It Is

A standard library string type.

### What It Does

Stores and manages a sequence of characters.

### How to Use

Declare a `std::string` variable and initialize it with text.

### Requirements

`<string>`  // Provides `std::string`.

### Representation

```cpp
#include <string>

std::string name = "James";
```
