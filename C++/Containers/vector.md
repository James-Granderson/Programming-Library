# vector

**Concept:** C++
**Action:** Declare
**Object:** `std::vector`
**Classification:** Container
**Environment:** Any C++ compiler
**Path Type:** N/A

---

### What It Is

A dynamic sequence container from the `C++` standard library.

### What It Does

Stores elements in a contiguous, dynamically sized sequence.

### How to Use

Declare a `std::vector` with the type of elements it will store.

### Requirements

`<vector>`  // Provides `std::vector`.

### Representation

```cpp
#include <vector>

std::vector<int> numbers = {1, 2, 3};
```
